# Loan-Performance-Analysis-Power-BI-
Power BI dashboard analyzing loan performance, repayment trends, and default risk using dynamic DAX insights.

## Project Overview

This project focuses on analyzing loan performance using Power BI to evaluate repayment behavior, default trends, and overall portfolio health. The goal is to transform raw loan data into actionable insights that support better credit risk management and lending decisions.

## Objectives

- Assess overall loan portfolio performance
- Analyze repayment and default trends over time
- Identify patterns in loan issuance and risk behavior
- Provide insights to support data-driven financial decisions

## 📁 Dataset Description

The dataset contains approximately 9,500+ loan records with key variables such as:
- Loan Date  
- Default Flag (0 = No Default, 1 = Default)
- Not Fully Paid Indicator
- Income Group
- FICO Category
- Debt-to-Income (DTI) Group
- Interest Rate, Installment, and other financial metrics

## Key Performance Indicators (KPIs)

- Total Loans: 10K
- Fully Paid Loans: 8K
- Defaulted Loans: 2K
- Default Rate: 16.01%
- Repayment Rate: 83.99%

## Dashboard Features
### 1. Loan Volume Trend

Tracks monthly loan issuance over time.

**Insight:**
Loan issuance remained relatively stable with fluctuations across months, peaking at 228 loans and dropping to 168, indicating possible seasonal demand patterns.

### 2. Default Trend Analysis

Monitors the number of defaulted loans over time.

**Insight:**
Defaults varied monthly, peaking at 41 cases and dropping to 22, highlighting periods of elevated credit risk rather than a one-time spike.

### 3. Loan Performance Breakdown

Visual representation of fully paid vs non-performing loans.

**Insight:**
Approximately 84% of loans were fully paid, demonstrating strong portfolio performance, while 16% defaulted, indicating moderate but persistent credit risk.

### 4. Executive Summary Insight

The loan portfolio shows strong repayment performance, with the majority of loans successfully repaid. However, a default rate of approximately 16% suggests ongoing credit risk exposure. Despite stable lending activity, fluctuations in default trends indicate the need for improved monitoring and risk assessment strategies, particularly during high-risk periods.

## Key Insights

- Loan performance is generally strong with high repayment rates
- Default rates remain significant and require attention
- Loan issuance is stable but influenced by seasonal patterns
- Risk is persistent and varies across time periods
