# Loan-Performance-Analysis-Power-BI-
Power BI dashboard analyzing loan performance, repayment trends, and default risk using dynamic DAX insights.

## Objectives Project Overview

This project analyzes loan portfolio performance using Power BI, with a focus on repayment behavior, default trends, and loan demand patterns.
It transforms raw loan data into clear, actionable insights to support better financial and credit risk decisions.

## Objectives

- Assess overall loan repayment performance
- Identify trends in loan issuance over time
- Analyze default patterns and risk periods
- Deliver data-driven insights for credit risk management

## Key Metrics

-Total Loans: 10,000
- Fully Paid Loans: 8,399 (83.99%)
- Defaulted Loans: 1,601 (16.01%)
- Peak Loan Volume: 228
- Lowest Loan Volume: 168
